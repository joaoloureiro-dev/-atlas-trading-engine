# Atlas

Secure autonomous multi-market AI trading platform.

## Markets

- Cryptocurrency
- Stocks
- Forex
- Futures
- Options
- Commodities

## Core Principles

- Zero custody of user funds
- Multi-tenant by design
- AI cannot override hard risk limits
- Agents cannot access broker credentials
- Broker execution is isolated
- Every financial action is auditable
- Paper / Shadow / Live environments are isolated
- Security before performance

## Trading Modes

- PAPER
- SHADOW
- LIVE

## Languages

- English
- Portuguese
- Spanish
- French
